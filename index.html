PostPilot Privacy Policy

Effective date: November 22, 2026

1. Introduction

PostPilot is an AI-powered social media assistant that helps users turn their ideas and learning notes into social media drafts for platforms such as X and LinkedIn. This policy explains how information is processed when using PostPilot.

2. Information We Process

Depending on how you use PostPilot, the application may process:

  • Messages and learning notes you send to the Telegram bot.
  • Generated social media drafts and editing instructions.
  • Telegram user identifiers used to manage conversations and restrict access.
  • Publishing records, including platform, post identifier, content hash, status and timestamp.
  • API credentials configured by the application operator to connect external services.

3. How Information Is Used

Information is processed to:

  • Understand user messages and generate social media drafts.
  • Edit and manage generated content.
  • Maintain conversation context.
  • Check publishing history and prevent duplicate posts.
  • Publish content when the authorized user explicitly approves and requests publishing.

4. Third-Party Services

PostPilot integrates with or may use the following services:

  • Telegram: Handles bot messages and communication with users.
  • Groq: Processes relevant text inputs to generate and edit social media drafts using AI.
  • X: Receives approved content when the user requests actual publishing.
  • LinkedIn: May receive approved content if LinkedIn publishing is enabled in a future version.

These services process information under their own privacy policies and terms. PostPilot does not control their independent data practices.

5. Data Storage and Security

PostPilot uses local application storage for publishing history. Conversation state is maintained in application memory and may be lost when the bot restarts. API credentials are configured locally by the application operator.

Reasonable measures are taken to protect application data and credentials. However, no method of electronic storage or transmission is completely secure.

6. Publishing and User Approval

PostPilot provides an approval step before publishing. Actual publishing occurs only when the authorized user explicitly requests it.

When Test Mode is enabled, publishing is simulated and content is not sent to the public social media platform.

7. Data Sharing

PostPilot does not sell personal information. Information may be processed by the third-party services required to provide the application's functionality.

8. Data Retention and Deletion

Publishing history is retained in the application's local database until the application operator removes it. Conversation state is maintained in memory while the application is running.

Users can contact the project maintainer with questions or requests concerning their information.

9. Changes to This Policy

This privacy policy may be updated as PostPilot develops and introduces additional features. Changes will be published on this page.

10. Contact

For privacy-related questions, contact the project maintainer through the PostPilot GitHub repository . Please do not include sensitive personal information in public issues.
